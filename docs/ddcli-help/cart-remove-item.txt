Usage: dd-cli cart remove-item [OPTIONS]

  Remove a single line item from a cart by cart_item_id.

  Removes one line but keeps the cart available for future additions
  (cart_uuid stays valid). The response's `cart` carries `group_cart_url` for
  group carts (same as `cart show`); `null` for personal carts.

  To CHANGE A QUANTITY (rather than drop the item entirely), the cleaner path
  is `cart add-items` — see its docstring for delta-add semantics.

  Chains with:
    Upstream   — --cart-uuid from `cart add-items` / `order reorder`;
                 --cart-item-id from `cart show` items[].id (NOT menu item_id)
    Downstream — cart_uuid stays valid; verify with `cart show`, then proceed
                 to `order preview` / `order submit` / `order checkout-url`

  Example:

    dd-cli cart remove-item --cart-uuid 0a1b2c3d-... --cart-item-id line_42

Options:
  --cart-uuid TEXT     Cart UUID from a previous `cart add-items` call.
                       [required]
  --cart-item-id TEXT  Cart-line id from `cart show` items[].id field (NOT the
                       menu item_id; call `cart show` first to get this).
                       [required]
