### Signing + env
- **Inbound vs outbound signing asymmetry** — INBOUND (`verifyPartner*Signature`) verifies EXACT raw bytes / explicit newline challenge, NO canonicalization; OUTBOUND (`signPayload`) signs `sha256(canonicalJson)`. Re-stringifying an inbound body before verify fails on key-order/whitespace. `readSignedBody` reads `c.req.text()` before parse for exactly this. → [[ed25519-window-signing]]
- **`ALLOW_TEST_PARTNER_PUBKEY` active on prod** (the old CORS_ORIGIN-inference bug) — gate is the IMMUTABLE `CLAWVILLE_ENV==='staging'` literal equality + a **module-load throw (partner-signature.ts:97-103)** crashing boot off-staging. NEVER reintroduce CORS_ORIGIN inference; NEVER use NODE_ENV ('production' on BOTH boxes). Staging box MUST also carry `CLAWVILLE_ENV=staging`. FIXED. → [[allow-test-pubkey-env-guard]]
