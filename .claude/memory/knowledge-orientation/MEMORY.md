## Known traps (read BEFORE any change in this domain — feeds Phase 0)
Phase-0 pre-flight checklist — read EVERY time before coding. Emphasis: the menu↔backend↔economics↔knowledge decoupling failures here are SILENT (no crash) and corrupt every other domain's onboarding.

1. **A surface left stale (the keystone decoupling bug).** A gameplay change updating only ONE of {Nori `knowledge[]`, connection SKILL.md, hosted-runtime} is the #1 silent defect — no crash, agents just play the wrong game. Same-diff all three. → [[three-surface-knowledge-sync]]
2. **Editing `town-guide.ts` instead of the orientation constant.** World-facts go in `CLAWVILLE_ORIENTATION_KNOWLEDGE` (`constants/orientation-skill.ts`) — Nori spreads it, every new avatar appends, the export prepends. Hand-editing only `town-guide.ts` drifts the avatar + export copies. → [[orientation-single-source]]
3. **A `requireAuth`-only chat route = E5 parity gap (OPEN).** `chat.ts:45` (system) + `chat.ts:158` (location) are HUMAN-ONLY (no `resolveAgentSession` branch) — a pure connected/hosted agent gets 401 and can't earn CT/score the weight-10 `agent.chat.turn` through them. VERIFY the gateway path covers agent chat earning BEFORE concluding lockout; if not, ADOPT auth-identity-session's resolver (don't reimplement) + carry a PARITY note. → [[chat-route-e5-parity-gap]]
4. **A manual contract change without a PROTOCOL_VERSION bump, or §3a bounds drifting from the executor.** `PROTOCOL_VERSION` (skill-protocol.ts:63 = 6) is the eager re-embed signal partners poll. A `buildProtocolManual` contract change (verb doc, bound, default, section) bumps it; §3a bounds are hard-mirrored literals of `npc-simulation.ts` executor constants that silently diverge. Co-sign with agent-protocol-partner + Codex pass + mock-Hatcher harness GREEN (PROTECTED PARTNER SURFACE). → [[protocol-version-consumed-seam]]
5. **A persona-wrong-but-DB-correct teacher.** A teacher answering as Pearl/cron despite a correct template/DB row is the eliza-runtime char-builder config-fallback, NOT the template. Persona is customization-FIRST; the seeder stamps `config.locationId` (system-npc-seeder.ts:197/:210) as defense. FIXED on prod (PR #159 / 8520fe1b). Diagnose at the runtime char-builder. → [[teacher-persona-customization-driven]]
6. **A reward double-mint or wrong /dash attribution.** System-agent chat caps one CT/XP per `(userId,slug)`/60s (in-memory limiter, single-pod); location chat has no cooldown (one CT/turn). CT via `creditClawTokens` ONLY (chat.ts:119/:310 — never `avatars.clawTokens`). Log `chatType:'system-agent'`+buildingId:null vs `chatType:'location'` so the /dash teacher metric (10 residents only) isn't inflated. → [[chat-reward-and-metric-discipline]]
7. **A seeder that drops a slug / breaks the singleton.** `ensureSystemAgents` upserts by `type='system-agent'` + `customization->>'slug'` (system-npc-seeder.ts:352/:397/:409) under the `platform_agents_system_singleton` partial unique index — NEVER by name; runs FIRST in boot (index.ts:468) to shrink the 503 race. New system agent = template + register in `SYSTEM_AGENT_TEMPLATES` + ship. → [[system-npc-seeder]]
8. **An LLM-key leak / provider drift back to Gemini/Anthropic.** OpenAI is the SOLE backend (2026-06-05, npc-conversation-engine.ts:8/:41); embeddings PINNED in code (text-embedding-3-small/1536). Eliza chat MUST go through the runtime (no direct bypass); transient/banter stay stateless non-Eliza; never log `OPENAI_API_KEY`; missing key degrades to canned fallback, never throws. → [[llm-provider-openai-only]]
9. **Mis-tagging a leaderboard `skill_md.fetched` (partner farming rank, or excluding a legit end-user).** End-user (Lucia cookie OR live agent session) = organic (`via=undefined`, counts under 11/day cap); partner-key bulk poller = `via='partner-import'` (carved out). Never trust a bare `X-Clawville-Agent-Id` header as identity. `clawville-play` stays always-public. → [[skill-md-gating-leaderboard-tag]]
10. **Trusting a non-ledger agent session to own its userId on a support/identity read.** Only attribute userId/avatarId when `resolved.ledgerCapable` is true (support.ts:160) — otherwise an untrusted agent could mis-attribute a ticket or burn a victim's rate-limit bucket. → [[support-all-subject-fail-open]]
11. **STALE HINT — 'the connection SKILL.md endpoint does not exist (infra gap).'** NO LONGER TRUE. `GET /api/skills/protocol/skill.md` + `GET /api/skills/manifest.json` exist and serve the manual + content-hash poll. Treat the endpoint+manifest as FIXED (Hatcher Phase C); the eager-on-connect/hosted-runtime injection is the remaining best-effort gap. → [[three-surface-knowledge-sync]]
